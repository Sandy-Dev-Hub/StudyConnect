# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in StudyConnect, please report it privately rather than opening a public GitHub issue.

Please include:

- A description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Any relevant screenshots or logs

Please do not include passwords, API keys, database credentials, or other sensitive information in the report.

## Supported Versions

Security fixes are primarily provided for the latest production version of StudyConnect.

| Version | Supported |
|-------- |-----------|
| Latest  |        ✅ |
| Older versions | ❌ |
